# CongaFour

Four-bar live conga and bongo pocket desk for bedroom producers and AI-music finishers.

Suno and loop DAWs print a kit that lands every hit on the grid. CongaFour seats live FluidR3 percussion, plays stiff kit vs pocket, and exports a punch list, WAV, and GM percussion MIDI.

Live samples only. No oscillators. Audio never leaves the tab.

Distinct from WalkEight (walking bass), RiseEight (energy rise), GhostEight (kit ghosts), and NeedThree (nylon/shaker/pad).
